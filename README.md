## Вывод по работе

В ходе выполнения практической работы были изучены и применены основные инструменты отладчика Microsoft Visual Studio.

### Точки останова
Использовались обычные, условные и временные точки останова, позволяющие приостанавливать выполнение программы в нужной строке кода для анализа состояния приложения и поиска ошибок.

### Окна наблюдения
В процессе отладки применялись окна:
- «Локальные»
- «Авто»
- «Контрольные значения»

Данные инструменты позволили отслеживать значения переменных и контролировать изменения состояния программы на различных этапах выполнения.

### Пошаговое выполнение
Использовались режимы:
- Step Into
- Step Over
- Step Out

Пошаговое выполнение позволило детально проследить последовательность выполнения инструкций и определить участки программы с некорректной логикой работы.

### Стек вызовов
Окно Call Stack использовалось для анализа последовательности вызова методов и определения источника возникновения ошибок.

### DataTips
Для быстрого просмотра значений переменных применялись всплывающие подсказки DataTips, отображающие данные непосредственно в редакторе кода.

## Исправленные ошибки

### Приложение «Фибоначчи»
В процессе отладки была обнаружена ошибка `IndexOutOfRangeException`, связанная с выходом за пределы массива. Причиной ошибки являлась некорректная инициализация коллекции и отсутствие проверки границ массива. Ошибка была устранена путём корректировки логики работы со списком и настройки размера коллекции.

### Приложение «Галактики»
В приложении была обнаружена ошибка в конструкции `switch`, вызванная визуальным сходством символов `'l'` (строчная буква L) и `'I'` (заглавная буква i). Из-за этого выполнялась неверная ветвь программы. После проверки и исправления символа программа начала корректно определять тип галактики.
