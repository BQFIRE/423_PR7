# Практическая работа №7  
**Тема:** Отладка программы различными способами в Visual Studio  

**Выполнили:** Поджигайло Владимир, Рурахма Кадиев, группа 423ИСиП  

## Цель работы
Изучить работу отладчика Visual Studio: точки останова, пошаговое выполнение, просмотр переменных и стек вызовов.  

---

## Задание 1. Фибоначчи
Программа **Fibonacci** выводит 5-е число последовательности Фибоначчи.

**Отладка:**
- точка останова на `sum = n1 + n2;`
- пошаговое выполнение (F10)
- просмотр переменных `n1`, `n2`, `sum`

---

## Задание 2. Галактики
Программа **Galaxies** выводит информацию о нескольких галактиках.

**Отладка:**
- точка останова на `Console.WriteLine($"Название: {galaxy.Name}");`
- пошаговое выполнение
- просмотр массива объектов
- окно **Локальные**

---

## Задание 3. Буквы
Программа **ArrayExample** перебирает массив букв и выводит их накопительно с счётчиком.

**Отладка:**
- точка останова на `SendMessage(name, a[i]);`
- пошаговое выполнение
- просмотр переменных `letters`, `name`, `a[i]`
- окно **Локальные**, **Авто**
